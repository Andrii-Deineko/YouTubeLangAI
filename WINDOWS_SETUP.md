# Руководство по запуску и настройке на Windows (YouTube Lang AI)

Данный проект представляет собой расширение для браузеров на базе Chromium (Google Chrome, Microsoft Edge, Brave, Яндекс Браузер), разработанное по стандарту **Manifest V3**.

---

## ⚡ Быстрый старт на Windows

Для Windows добавлены готовые скрипты:

1. **`install.bat`** — однократная установка зависимостей.
2. **`build.bat`** — полная сборка расширения в папку `dist/`.
3. **`dev.bat`** — запуск сервера разработки Vite с поддержкой HMR.
4. **`setup.ps1`** — автоматический скрипт настройки и сборки для PowerShell.

---

## 🛠 Ручной запуск через терминал (PowerShell / CMD)

### Решение проблемы с политикой выполнения скриптов (PowerShell)
Если при выполнении команды `npm` в PowerShell появляется ошибка:
```
File C:\Program Files\nodejs\npm.ps1 cannot be loaded because running scripts is disabled on this system
```
Это стандартная политика безопасности Windows PowerShell. Решить её можно двумя способами:

1. **Рекомендуемый способ (использовать `npm.cmd`):**
   ```powershell
   npm.cmd install
   npm.cmd run build
   ```
2. **Либо разблокировать выполнение локальных скриптов для текущего пользователя:**
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
   ```
   После этого стандартные команды `npm install` и `npm run build` работают без ограничений.

## 🧩 Установка расширения в браузер

После завершения сборки готовые файлы расширения находятся в директории:
```
S:\Dev\YouTubeLangAI\dist
```

1. Откройте браузер на базе Chromium (Google Chrome, Microsoft Edge, Brave, Яндекс.Браузер).
2. В адресной строке перейдите по адресу:
   - В Chrome / Brave / Yandex: `chrome://extensions/`
   - В Microsoft Edge: `edge://extensions/`
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
4. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
5. В открывшемся окне проводника выберите папку:
   ```
   S:\Dev\YouTubeLangAI\dist
   ```
6. Расширение появится в списке под названием **«YouTube Lang AI»** и будет автоматически активировано на всех страницах YouTube (`youtube.com`).

## ⚙️ Настройка AI (BYOK) и AnkiConnect на Windows

### 1. Подключение AI провайдера
Нажмите на значок расширения на панели браузера и перейдите во вкладку **Settings**:
- **OpenAI**: Base URL `https://api.openai.com/v1`, укажите API Key и модель (например, `gpt-4o-mini`).
- **Google Gemini**: Base URL `https://generativelanguage.googleapis.com/v1beta/openai`, укажите ключ Google AI Studio и модель (например, `gemini-2.5-flash`).
- **OpenRouter**: Base URL `https://openrouter.ai/api/v1`.
- **Ollama (локально на Windows)**:
  - Установите Ollama для Windows (работает в фоновом режиме на `http://127.0.0.1:11434`).
  - Укажите Base URL: `http://127.0.0.1:11434/v1`.
  - Модель: `llama3.1` (или любая скачанная модель).
- Нажмите **«Проверить подключение LLM»** для проверки связи.

### 2. Подключение Anki Desktop на Windows
1. Скачайте и запустите [Anki для Windows](https://apps.ankiweb.net/).
2. В Anki откройте: **Инструменты → Дополнения → Загрузить дополнение**.
3. Введите код плагина AnkiConnect: **`2055492159`** и перезапустите Anki.
4. AnkiConnect по умолчанию слушает адрес `http://127.0.0.1:8765`.
5. В настройках расширения нажмите **«Test AnkiConnect»** (при первом вызове браузер запросит разрешение для `127.0.0.1`).

## ⌨️ Горячие клавиши на видео YouTube

| Клавиша | Действие |
| :--- | :--- |
| `R` | Повторить текущую фразу субтитров с начала |
| `A` или `←` | Перемотать на предыдущую фразу субтитров |
| `D` или `→` | Перемотать на следующую фразу субтитров |
| `S` | Быстро сохранить активное/выделенное слово в словарь |
| `Esc` | Закрыть всплывающее окно перевода и возобновить воспроизведение |
| Зажатый `Alt` | Временно показать скрытый текст в режиме Active Listening |
